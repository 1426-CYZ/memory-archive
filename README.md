# 记忆档案局 · 灯还亮着

基于 GitHub Pages 的第一人称探索 WebApp / 课堂 MVP。

## 作品介绍

在个人经历每月备份、清除和恢复的世界里，玩家扮演夜班档案员，通过员工终端签收任务，调查一盏台灯、一台收音机与一封信，替陈屿找回关于回家的记忆。

## 可玩的内容

- 可自由行走的三维档案局，含接待、阅览、值班、休息与记忆接入区。
- 复古员工终端、任务签收、档案查询与线索状态。
- 台灯接线、收音机调谐、拆信记录三种物件操作。
- 可暂停、回放与切换视角的三维记忆，以及恢复或超时两种结果。
- 纸飞机、星球球、不倒翁鸭、值班猫、咖啡与浇水等小互动。

## 操作

WASD 移动，鼠标环顾，Shift 快走，E 调查，T 员工终端，J 档案夹，Esc 暂停菜单。

点击“开始值班”后进入场景；在员工终端签收任务后开始八个游戏小时的恢复期限。

独立浏览器支持持续鼠标捕获。受限内置预览会自动启用兼容环顾，靠近左右边缘可持续转向。

## 部署

将本目录内的 index.html、README.md 和 .nojekyll 上传至仓库根目录。在 Settings → Pages 中选择 Deploy from a branch，使用 main 分支与 /(root)，保存即可。

页面为完整的静态网页，运行不需要后端、账号或 API 密钥。状态保留在本次打开期间，刷新会重新开始。

## 技术与许可

使用 HTML、CSS、JavaScript 与 Three.js r159。三维场景和纹理由代码生成；Three.js 的 MIT 许可已完整包含于 index.html。
